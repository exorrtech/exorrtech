## What I am working on

**InspectorReady ZW** is a live web app that helps Zimbabwean schools, clinics and small businesses prepare the documentation POTRAZ asks for during a data-protection inspection. It turns plain answers into a printable Record of Processing Activities and an eight-item evidence pack. Built with Node.js, Express, PostgreSQL and EJS.

[Live app](https://inspectorready-zw.onrender.com) · [Source code](https://github.com/exorrtech/inspectorready-zw)
